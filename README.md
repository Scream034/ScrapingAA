### О проекте

#### Проект был создал в рамках задачи по созданию desktop-приложения для облегчения работы с данными контент-менеджера.

### Прирост производительности:

- Заполнение характеристик товаров: +60%
- Загрузка изображений: +85%
- Заполнение первоначальных данных (главных или что-то вроде SEO): +50%
- Сортировка/Форматирование/Поиск: +60%
- **Полный прирост**: 255%
- **Точные цифры**: с 10 минут до 1 минуты (максимальное)

### Небольшие детали:

- Разработал десктопное приложение для автоматизированного сбора, обработки и анализа данных с нескольких веб-сайтов (тематика: спецтехника/авто).
- Спроектировал и реализовал модульную архитектуру парсеров для легкого добавления поддержки новых сайтов.
- Использовал Playwright для навигации по динамическим страницам, заполнения форм и извлечения структурированных данных.
- Разработал собственные алгоритмы (AEXU, ASC) для автоматического извлечения числовых характеристик с единицами измерения и последующей классификации/сортировки характеристик по категориям.
- Интегрировал библиотеку MyStem для лемматизации и морфологического анализа русскоязычного текста характеристик.
- Реализовал функционал экспорта обработанных данных в формат Excel (.xlsx) с помощью ClosedXML.
- Создал пользовательский интерфейс на Godot Engine (C#) для управления процессом парсинга, просмотра и редактирования данных.
- И многое другое... (может быть дополню)
